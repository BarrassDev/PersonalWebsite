# Listography

A basic Next.js version of the party game **Listography**: get a list prompt, start the 30-second timer, and write your list — score a point for every answer nobody else wrote down.

## Features

- **AI-generated prompts** — a "New Question" button fetches a fresh Listography-style prompt, generated by Claude through the [Vercel AI SDK](https://ai-sdk.dev) and AI Gateway. Recently used prompts are sent along so you don't get repeats.
- **Togglable 30-second timer** — start / pause / reset, with a toggle to turn the timer off entirely.
- **Offline-friendly fallback** — if the AI Gateway isn't reachable (e.g. local dev without a key), prompts are served from a built-in question bank instead.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

To get AI-generated questions locally, create a `.env.local` with an [AI Gateway API key](https://vercel.com/docs/ai-gateway):

```
AI_KEY=your-key-here
```

Without a key the app still works using the fallback question bank.

## Deploying to Vercel

Deploy as a standard Next.js app.

Environment variables:

| Variable | Default | Purpose |
| --- | --- | --- |
| `AI_KEY` | — | Vercel AI Gateway API key used to generate questions |
| `AI_GATEWAY_API_KEY` | — | Fallback key name (the AI SDK's default); OIDC is used on Vercel if neither key is set |
| `AI_GATEWAY_MODEL` | `anthropic/claude-opus-4.5` | AI Gateway model slug used to generate questions |
